# 👕 Outfit Planner App (Early Prototype)

An early-stage prototype for an app that helps you decide what to wear based on **weather, personal style, and clothing availability**.

The app lets users upload their clothes, tag them by style and fit, and generates outfit suggestions while avoiding items marked as dirty or unavailable.

This project is focused on **testing the idea and core flow**, not polish yet.

---

## 🚧 Status

**Stage:** Early testing / MVP  
**Built with:** Dyad + React (Vite)  
**Deployment:** Local + ngrok (testing only)

Expect rough UI, incomplete features, and frequent changes.

---

## ✨ Features (Current & Planned)

- Upload clothing images
- Tag clothes by type, style, fit, season
- Outfit suggestions based on weather
- Mark clothes as dirty to exclude them
- Style preference learning (basic)
- Calendar-aware outfits (planned)
- Smart speaker integration (planned, premium)
